## Code Generation

This SDK is generated from the [OpenFGA API spec](https://github.com/openfga/sdk-generator) using OpenAPI Generator 6.4.0. Many files in `lib/openfga/` are auto-generated; the next generation run overwrites them, so edits won't stick.

**Auto-generated files** carry this header:

```ruby

#OpenFGA
# ...
# Generated by: https://openapi-generator.tech
```

## Architecture

The SDK is layered: the high-level `SdkClient` sits atop a generated `OpenFgaApi` wrapper, which uses a generated `ApiClient` (Faraday) for HTTP.

```
SdkClient (lib/openfga/client/openfga_client.rb)
  └── OpenFgaApi (lib/openfga/api/open_fga_api.rb)  [auto-generated]
        └── ApiClient (lib/openfga/api_client.rb)    [auto-generated, Faraday]
              └── TokenManager (lib/openfga/token_manager/token_manager.rb)
```

**`SdkClient`** is the main public interface:
- Store management: `create_store`, `list_stores`, `get_store`, `delete_store`
- Authorization models: `write_authorization_model`, `read_authorization_model`, `read_authorization_models`
- Tuple operations: `read`, `write`
- Authorization checks: `check`, `batch_check`
- Expansion & listing: `expand`, `list_objects`, `list_relations`, `list_users`
- Change feed: `read_changes`
- Assertions: `read_assertions`, `write_assertions`
- Raw access: `execute_api_request`

**`TokenManager`** is pluggable with three implementations:
- `NoopTokenManager` — no auth (local dev)
- `StaticTokenManager` — API token / bearer token
- `Oauth2TokenManager` — OAuth2 client credentials flow

**Models** are plain data objects (auto-generated) with attribute accessors and JSON serialization, all under `OpenFga::Models`.

**Retry logic** is built into `SdkClient` with exponential backoff. The relevant constants are in `lib/openfga/constants.rb`: `DEFAULT_MAX_RETRY = 3`, `MAX_BACKOFF_TIME_IN_SEC = 120`.

## Development

### Prerequisites

- Ruby >= 3.2 (use `.tool-versions` with asdf)
- Bundler
- Docker (for running OpenFGA locally)

### Install dependencies

```sh
bundle install
```

### Run tests

```sh
make test
# equivalent: bundle exec rspec
```

Tests stub HTTP with WebMock, so no live server is needed.

### Run linting

```sh
make lint
# equivalent: bundle exec rubocop -A
```

The `-A` flag auto-corrects safe offenses. Run without it to see violations only:

```sh
bundle exec rubocop
```

### Run examples

Examples require a running OpenFGA server. Start one with Docker:

```sh
make start-openfga   # docker run -d --rm --name openfga-examples -p 8080:8080 openfga/openfga:latest run
```

Then run an example:

```sh
make run-example1            # Full-featured example (no extra config)
make run-api-executor        # Low-level API executor example
```

Stop the server when done:

```sh
make stop-openfga
```

### Makefile targets

| Target | Description |
|--------|-------------|
| `make test` | Run the full RSpec test suite |
| `make lint` | Run RuboCop with auto-correct (`-A`) |
| `make start-openfga` | Start OpenFGA server via Docker on port 8080 |
| `make stop-openfga` | Stop the Docker-managed OpenFGA server |
| `make run-<name>` | Run `example/<name>/main.rb` (e.g. `make run-example1`) |

## Commits

Follow [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/). Every commit message must have a type prefix:

```
<type>[optional scope]: <description>

[optional body]

[optional footer(s)]
```

Common types used in this repo:

| Type | When to use |
|------|-------------|
| `feat` | A new feature or capability |
| `fix` | A bug fix |
| `chore` | Maintenance, dependency updates, tooling |
| `ci` | Changes to CI/CD workflows |
| `docs` | Documentation only |
| `refactor` | Code restructuring with no behaviour change |
| `test` | Adding or fixing tests |

Examples:

```
feat: add list_users method to SdkClient
fix: retry logic not respecting max backoff time
chore: bump rubocop to 1.75.1
ci: add example integration tests workflow
docs: update README installation instructions
```

Breaking changes go in the footer:

```
feat!: rename check to check_tuple

BREAKING CHANGE: the check method has been renamed to check_tuple
```

## Verification

A change is ready when all three pass:

1. **Tests pass:**
   ```sh
   make test
   ```

2. **Linting passes:**
   ```sh
   make lint
   ```

3. **Examples run without error**: start OpenFGA first, then confirm `example1` and `api-executor` exit cleanly:
   ```sh
   make start-openfga
   make run-example1
   make run-api-executor
   make stop-openfga
   ```

> **Do not run `example2` automatically.** It requires a `.env` file with OAuth2 client credentials (`CLIENT_ID`, `CLIENT_SECRET`, issuer, audience). Running it without that config will fail.

## RuboCop Rules

`.rubocop.yml` sets `DisabledByDefault: true`, so only explicitly listed cops are active. Key rules:

### `Style/HashSyntax` — enforced shorthand (`always`)

Use Ruby 3.1+ hash shorthand syntax when the key name matches the local variable.

```ruby
# good
name = 'alice'
{ name:, age: 30 }

# good — key differs from variable, use normal syntax
{ user: current_user, role: :admin }

# bad
name = 'alice'
{ name: name, age: 30 }
```

This also enforces symbol keys over hash rockets:

```ruby
# good
{ store_id: '01H...', model_id: '01J...' }

# bad
{ :store_id => '01H...', :model_id => '01J...' }
```

### `Style/FrozenStringLiteralComment`

Disabled (`Enabled: false`). Skip the `# frozen_string_literal: true` comment. Hand-maintained files in `lib/openfga/client/` include it (e.g. `openfga_client.rb`), but it's not required.

```ruby
# fine — present in hand-maintained files
# frozen_string_literal: true

module OpenFga
  ...
end

# also fine — omitting it is not an offense
module OpenFga
  ...
end
```

### `Style/StringLiterals` — single quotes enforced

Use single quotes unless the string contains interpolation or a literal single quote.

```ruby
# good
api_url = 'http://localhost:8080'
store_id = '01HVMMBCMGZNT3SED4Z17JUSTIFY'

# bad
api_url = "http://localhost:8080"
store_id = "01HVMMBCMGZNT3SED4Z17JUSTIFY"

# fine — interpolation requires double quotes
message = "Store #{store_id} created"

# fine — contains a literal single quote
label = "it's ready"
```
